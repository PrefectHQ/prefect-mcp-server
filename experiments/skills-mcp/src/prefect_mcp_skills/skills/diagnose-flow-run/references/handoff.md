# Incident handoff

Use these three headings in order:

## Observed evidence

Include the full run UUID, current state, and the relevant error from its logs.

## Diagnosis and uncertainty

Explain the immediate failure supported by the evidence. Distinguish this from
hypotheses about why it happened; do not invent upstream outages or credentials.

## Suggested next check

Suggest one concrete check tied to the recorded error. State that no rerun or
configuration change was performed.
